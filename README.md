# 🗳️ U-PAC: United Platform for Accountability and Civic Engagement

Welcome to the **U-PAC** repository! Our mission is to build a civic platform where users can transparently engage with representatives, evaluate policies, and promote integrity in public office.

---

## 📌 Project Highlights
- Built with **Hugo** and **modular CSS**
- Implements **strict CSP** with **dynamic nonce injection**
- Integrates **per-page JavaScript and CSS** loading for performance and security
- Candidate search with **ZIP/address geolocation** and district filtering
- Support for **volunteer submissions**, donation tools, and more

---

## 🚀 Getting Started
### 1. Local Development
```bash
git clone https://github.com/anchorskov/u-pac-hugo.git
cd u-pac-hugo
npm install -g postcss-cli
hugo server --navigateToChanged
```

### 2. Cloudflare Integration
Push to the `main` branch to trigger deployment via GitHub → Cloudflare Pages.

### 3. Branch Workflow
Feature development is tracked in branches like `refactor-css`, then merged into `main` after review.

## 🧩 What We Need: U-PAC Community Roadmap
We’re building a tool for **transparent, verified, and democratic engagement** — and here’s where we need YOU 👇

### 1. 🎨 User Interface (UI)
- Create clean, accessible, mobile-friendly frontends for:
  - Voter dashboard
  - Candidate comparison view
  - Legislative alerts
  - Submission/survey forms

### 2. 🛡️ Secure User Registration
- Implement user signup/login flow (OAuth or email+code)
- Validate authenticity, limit spam/bots

### 3. 🗳️ Survey Generator + Response Collector
- Admin tools to build surveys
- Dynamic frontend rendering
- Response storage and summarization

### 4. 🧠 Issue & Legislation Tracker
- Fetch current bills from public APIs
- Auto-match to users' location and preferences

### 5. 📰 Autogenerated Newsletters
- Alerts for legislation, candidates, and surveys
- Personalized by district and interest

### 6. 📬 Contact Reps/Senators
- Convert user opinions to messages
- Enable direct contact (email/call/social)

### 7. 📊 U-Meters (Representative Scoring)
- Visualized rating system for reps
- User-submitted scores and feedback
